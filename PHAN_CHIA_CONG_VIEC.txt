Du an co 2 khu vuc chinh:

1. Owner Portal
   - Giao dien danh cho chu thu cung.
   - Dua theo cac anh trong folder Design_UI.

2. Hospital Admin Portal
   - Giao dien danh cho benh vien thu y My Dinh.
   - Danh cho le tan, bac si, nhan vien khach san thu cung va admin.

Muc tieu cua file nay la chia viec cho 2 nguoi lam song song, han che conflict Git va giu dung pham vi du an.

-------------------

- Khong nen lam truc tiep tren branch main.
- Moi nguoi nen tao branch rieng.

- Neu can sua file dung chung thi bao cho nguoi con lai truoc.

9. WORKFLOW CAN DEMO DUOC
-------------------------

9.1. Owner dat hotel booking, Admin xac nhan

OwnerHotelBookingPage
  -> createHotelBooking()
  -> AdminHotelBookingsPage thay booking pending
  -> Admin bam Confirm
  -> confirmHotelBooking()
  -> Owner nhan notification


9.2. Admin gui nhac lich kham

AdminAppointmentsPage
  -> Send Reminder
  -> Owner Dashboard/Notifications hien thi thong bao


9.3. Bac si tao ho so y te

AdminMedicalRecordsPage
  -> Create Medical Record
  -> OwnerMedicalRecordsPage thay ho so moi


9.4. Admin them daily care note

AdminHotelBookingsPage
  -> Add Daily Note
  -> Owner nhan cap nhat tinh trang thu cung

13. QUY DINH CODE STYLE
-----------------------

Component nen viet theo named export:

  export function ComponentName() {
    return <div>...</div>;
  }

Type import:

  import type { Pet } from "../../types/pet";

Tam dung relative import, chua can alias @/.

Vi du:

  import { Button } from "../../components/ui/Button";

Tailwind:

- Khong inline style neu khong can.
- Khong lap class qua nhieu; neu lap thi tach component.
- Giu mau sac theo theme trong tailwind.config.js.
