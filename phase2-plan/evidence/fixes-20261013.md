## A03 — Token đã xóa vẫn đọc Core

- `backend/src/phase2/currentAccount.ts` kiểm account/role trước API xác thực trong Core, kể cả proxy qua Core: mất account → 401, role đổi → 403, DB lỗi → 503 đã bỏ chi tiết nội bộ. Không cache quyền giữa request. Middleware đặt sau runtime limiter.
- Public login/register/activation, health/docs/rescue và callback VNPay vẫn chạy với bearer cũ. Không sửa app.ts legacy có lịch sử chỉnh sửa riêng.
- Unit kiểm xóa/đổi role/outage/token sai/public routes/private lookalike. Docker kiểm DB thật: đổi role/xóa admin fixture rồi dùng JWT cũ nhận 403/401, `/auth/me` 401.
- **Giới hạn:** sửa lỗi đã tái hiện tại Core. Clinic/Notification truy cập trực tiếp vẫn xác minh JWT theo thiết kế đọc độc lập. Không tuyên bố thu hồi tức thì mọi service, đổi mật khẩu hủy mọi token hoặc hủy request đang chạy. Mở rộng cần cơ chế revocation và tiêu chí riêng, không âm thầm buộc service đọc phụ thuộc Core.
